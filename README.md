# trainee_compact

Site institucional da Nutriação. Abra main.html no navegador ou use o Live Server do VS Code.

## Organização

- main.html: conteúdo e estrutura da página.
- assets/css/styles.css: folha de estilos única, com base, layout, detalhes visuais e regras responsivas.
- assets/img/: fotos, logos e ícones usados pela página.

As variáveis de cores, contornos e espaçamentos ficam no início de assets/css/styles.css.
