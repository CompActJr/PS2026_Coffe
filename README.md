# trainee_compact

Site institucional da Nutriação. Abra main.html no navegador ou use o Live Server do VS Code.

## Organização

- main.html: conteúdo e estrutura da página.
- assets/css/styles.css: folha de estilos original.
- assets/css/layout.css: estilos que estavam embutidos no HTML, preservando o layout original.
- assets/css/details.css: contornos dos cards e divisórias entre seções.
- assets/img/: fotos, logos e ícones usados pela página.

Para ajustar a força dos contornos ou a cor das divisórias, edite as variáveis no início de assets/css/details.css.
